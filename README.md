# **Midnight Munch**

A 2D platformer set at midnight where the player collects food while avoiding obstacles.

## 🎮 How to Play

**Controls**
* Arrow Keys: Up, Left, Right
* Space: Jump
* W / D: Move
* Esc: Pause

**Goal**
Collect all food items scattered in each level.

**Win Condition**
Gather all food and reach the level exit.

**Lose Condition**
Health reaches zero or an enemy catches you.

## 💾 Saving System
* The game includes a **manual save system**
* Players can save progress from the **pause menu**
* Saved data includes:
  * Current level
  * Score
  * Player stats
* Load game option available on startup or pause menu

## ⚙️ How to Run
* Requires **Godot 4.4.1** to open and run the source project
* Or run the exported **.exe** (no installation needed)

## 📊 Features
* 5 playable levels
* Manual save + load system
* Player health system
* Health pickup item
* Collectible food items
* Score and death tracking
* Pause menu
* Game Over & Game Complete screens
* Background soundtrack + sound effects
* Updated sprites and level designs
